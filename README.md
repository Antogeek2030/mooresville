# HVAC Repair Mooresville NC

Simple, fast, SEO-friendly Astro website for local HVAC repair services.

**Site:** https://hvacrepairmooresvillenc.com

## Features

- Homepage with USP, Call Us & Get a Quote buttons, hero image, 3 testimonials, and embedded map
- Core Services page (6 services)
- Service Areas page (Mooresville & Lake Norman communities)
- Contact Us page with quote form and map
- Blog with HVAC tips
- robots.txt + automatic sitemap
- LocalBusiness / HVACBusiness schema markup
- Consistent NAP: 149 Rolling Hill Rd, Mooresville, NC 28117 | (704) 799-0123
- Minimal JS, optimized for Google PageSpeed

## Commands

```bash
npm install
npm run dev      # local development
npm run build    # production build
npm run preview  # preview production build
npm run deploy   # deploy to Cloudflare (if configured)
```

## Notes

- Phone number is a placeholder – replace with your real number in `src/consts.ts`.
- Form on Contact page uses Netlify form attributes; adapt for your host.
- Hero image is in `public/hero-hvac.jpg`.
